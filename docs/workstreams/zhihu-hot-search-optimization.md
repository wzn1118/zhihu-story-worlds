# 知乎热搜与搜索优化

## 修改

- 动态热榜/推荐卡片点击优先使用页面中已校验的知乎站内链接，避免列表重绘后控件 ID 失效。
- 后端只限制没有链接的账号操作按钮，不再根据整张热榜卡片标题误判“关注”等普通文字。
- 页面导航等待信息流或热榜节点完成异步渲染，并增加短暂稳定窗口。
- `ZhihuWorkspace` 遇到动态列表造成的过期控件时刷新当前 frame，给出可重试提示。

- `npm run build` 通过。
