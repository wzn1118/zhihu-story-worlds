# 黑底页面修复

根因是大量剧情背景和封面指向不存在的文件，图片加载失败后原组件返回空内容，舞台只剩深色底。透明人物绑定正常并不能补齐这些背景。

已在当前游戏加入按地点选择的九类本地场地示意图，区分现代与古代室内，覆盖仓库、房间、走廊、厅堂、庭院、森林/山洞、街道、海岸和船上。图片加载期间或失败时显示示意图，正式图片成功加载后移除示意图；完整 CG 保持原图和既有构图，不叠加透明人物。缺失封面的书库卡片、详情和世界序章改用排印封面，场景与结局遮罩也调整了亮度。

示意图属于本地备用画面，不是新批准的美术。`render_game_to_text` 保留原背景的真实加载状态，并另列 `backgroundFallback`，不会把缺少正式图片的问题隐藏在批准数量里。
