# 刘看山记忆系统

2026-09-13

刘看山现在有一层独立的长期记忆档案，建立在已有真实通关记录之上，不生成虚假的游玩经历。

- `LiukanMemoryStore.profile(playerId)` 汇总不同故事数、结局数、已保存场景数和最近一次结局。
- `GET /api/liukan/memories?playerId=...` 继续返回原有 `memories`，同时返回 `profile`，保持旧客户端兼容。
- 聊天仍只把实际走过的章节、选择、线索和已到达结局交给中转，不会把未走过的路线当成记忆。
- 记录继续按玩家隔离、最多保留50条，并通过原子写入避免并发覆盖。

验证：`tests/liukan-activity.test.ts` 新增记忆档案统计测试；活动/阅读视图测试 10/10 通过，`tsc --noEmit` 通过。真实本机数据返回 `local-player` 的 4 部故事、4 个结局、29 个场景，最近结局为《保留证据》。
