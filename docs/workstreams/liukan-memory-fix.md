# 刘看山结局回忆补全修复

日期：2026-09-12

## 修复内容

`server/liukan/memory.ts` 之前只要发现相同故事版本、世界和结局标题，就
保留第一次保存的记录。玩家在多段结局的第一段停留后继续阅读，后续已验证
的段落因此没有进入回忆。

现在只有在以下条件同时成立时，才用新快照补齐既有记录：

- 同一故事、世界、版本和结局；
- 场景数、场景标题与已选选择完全相同；
- 只有最后一个结局场景从既有文本的前缀继续增长。

补齐保留首次 `completedAt`。短快照、改写文本、不同的早期场景或另一条
同名结局路线均不会改写原记录。版本不同仍是独立记录，持久化上限仍为 50。

## 验证

新增 `tests/liukan-memory.test.ts`，覆盖：

- 段落 0 到完整结局的连续补齐、重载和短快照回退；
- 同名结局的另一条选择路线不覆盖既有回忆；
- 改写过的历史或结局文本不合并；
- 并发且乱序的阅读快照保留最长已验证文本；
- 50 条上限、版本隔离、非法游戏历史和未读段落校验。

执行 `node --import tsx --test tests/liukan-memory.test.ts tests/liukan-zhida.test.ts`：
13/13 通过。测试没有启动服务、浏览器、创作模型或外部请求。
