# 刘看山引导的真实模块聚焦

本轮范围是修复引导：每一步进入对应页面或子面板后，才定位真实模块。

原实现把原文说明指向书库按钮，插图不存在时退回项目列表，存档和结局还与侧边栏按钮共用标记。现在所有步骤采用唯一内容标记，删除跨模块回退；隐藏页面、关闭的折叠区不参与定位。尚未准备好的目标会等待，读取失败提供重新打开。

世界序章读取已有世界，原文步骤打开实际阅读器，知乎步骤进入工作台内的知乎页面。工作台通过 `tourStep` 属性切换粘贴选项卡和展开连接配置，避免初次挂载时漏接事件。进度与插图步骤选择已有项目的实际模块；无项目时显示对应空态，不创建演示项目。

引导卡按目标位置限制高度，小窗口里说明可以滚动，导航按钮保留在卡片内。退出时恢复此前页面和弹窗，异步子页面响应通过导航序号失效，避免退出后重新弹出。

验证脚本：`node --import tsx scripts/verify-liukan-tour-focus.ts`。

脚本逐步检查 1440×1000、390×844、320×568、844×390 的真实模块，额外通过明确标记的空列表夹具检查无项目状态，并检查延迟响应后退出、键盘焦点、单标签及没有生成调用。结果和截图保存在 `output/liukan-tour-focus/`；以 `verification.json` 的最终结果为准。

原有“只介绍知乎按钮”“缺失目标回退父模块”的旧引导约定已被本轮用户的真实子页面聚焦要求替代。
