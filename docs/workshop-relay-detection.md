# 创作中转站自动检测

填写中转地址和 API 密钥后，工作台延迟 700 毫秒自动读取模型列表，优先选择文字模型，并实际发送一条简短的结构化生成请求检查连接。模型只能从返回列表选择；协议默认自动检测，推理强度使用模型默认值。只有当前地址、密钥、模型和协议对应的检测通过，才启用保存。

列表表示密钥可访问的模型，当前所选模型另行验证生成能力。修改配置会取消过期请求、清除旧验证状态；失败可重试，不会退回手填模型。新接口不保存配置。留空密钥仅允许在同一个规范化后的已保存地址使用服务端原密钥。

接口：

- `POST /api/workshop/creative-config/models`：输入地址和密钥，返回规范化地址及模型列表。
- `POST /api/workshop/creative-config/check`：输入地址、密钥、模型和可选协议，返回检测通过的模型、协议及耗时。
- 现有保存、清除及使用环境配置接口继续使用；公网模式沿用原有的服务配置只读限制。
