# 行动台账：本轮实现与验证

日期：2026-09-06。本文件记录本轮新增功能。上一轮新增调查和配载玩法见 `investigation-logistics-verification.md`，不能将其场景增量再次算作本轮工作。

## 可见变化

随身手记新增“行动台账”，打开时默认显示。所有故事都能在其中查看当前章节、目标与实际资源；《蓝血》的夜间复核和《未来岛》的四格航次具有专门的逐项台账。

- 《蓝血》分开显示试卷、地理、时序、假说和独立交接。没有取得证据的复核显示“保留空缺”，不能因已经调查过就标成证实。证据栏目只列实际获得的线索。
- 《未来岛》分开记录复点、收货条款、三类货物、出航返航及试机。每类货物按真实进度显示已核验、已装船、已签收或已交接。备件签收不会代替试机。
- 四格配载图显示实际装过的货。返航后历史配载量与当前恢复的货位分别列出；原货返岛不会生成未取得的签收单。
- 未进入的支线不显示专项台账。已收束时未做项目显示“未执行”。读档、回退均从当前规范化时间线重算，未来证据和进度不会留在台账里。
- 手记栏目固定在标题下方，支持左右方向键及 Home/End 切换；各页具备对应的 tab/tabpanel 关联。切换页面回到内容顶部，个人笔记继续保留。

实现：`content/operation-journals.ts` 是两世界的内容定义；`src/operation-journal.ts` 只派生视图；`src/OperationJournal.tsx` 渲染状态。`server/worlds.ts` 编译时检查引用的场景、证据、货位和重复条目。没有改变 Ink 选项、数值、路线或存档格式。内容版本仍为 1.2.0。
