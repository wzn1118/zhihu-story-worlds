# 官网故事生成进度修复（2026-09-14）

点击生成后出现 `Unexpected token 'N', "Not Found" is not valid JSON`。

## 原因

官网发布目录为 `releases/oauth-20260914`。旧版使用所有账号共用的原文导入索引，登录用户可能拿到没有 `ownerId` 的历史项目。列表和生成接口允许这些记录，详情接口却返回纯文本 404。前端在检查 HTTP 状态前解析 JSON，且将列表与详情视为一次更新，因此详情失败会阻断全部进度刷新。

## 修复

- 同步账号独立的原文导入索引，同一账号重复导入保持幂等，不再复用未归属账号的旧项目。
- 官网列表和生成接口与详情采用相同归属规则，拒绝时返回 JSON 错误。
- 前端保留 HTTP 状态和错误码，妥善处理纯文本、HTML 和无效 JSON 响应。
- 列表刷新成功后立即显示；失效选择清除，暂时断网时保留已有列表并继续自动重连。

历史项目未被删除、迁移或强制指定归属；未绑定账号的旧项目不再出现在官网“我的改编”列表中。重新导入原文会创建当前账号自己的记录。
